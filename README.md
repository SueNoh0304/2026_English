# 쓰기 수행평가 안내판 (English Writing Performance Assessment Board)

교실 전자칠판·TV에 띄워두는 **수행평가 공지사항 + 초시계** 한 화면 웹페이지입니다.
HTML 파일 하나로 동작하며 외부 라이브러리가 없습니다.

## 사용 방법

1. `index.html`을 브라우저(Chrome / Edge)로 엽니다.
2. 노란 **전체화면 (F)** 버튼을 누르거나 `F` 키를 누릅니다.
3. 시작 버튼 또는 `Space`로 초시계를 시작합니다.

GitHub Pages를 켜면 주소로 바로 열 수 있습니다.
(Settings → Pages → Branch: `main`, folder: `/ (root)`)

## 기능

- 왼쪽: 시험 안내·형식 관련 공지, 상태 바(대기 중 → 진행 중 → 종료), 현재 시각
- 오른쪽: 카운트다운 / 스톱워치, 5·10·20·30·40분 프리셋 + 직접 입력, 진행률 게이지
- 남은 시간에 따른 색 변화(초록 → 5분 전 노랑 → 1분 전 빨강 깜빡임)
- 종료 시 `00:00` 고정, 화면 붉은 번쩍임, "종료!" 표시, 알림음 3회(Web Audio API)
- 화면 꺼짐 방지(Wake Lock API, 지원 브라우저)
- 1920×1080 고정 비율 화면을 창 크기에 맞춰 통째로 축소/확대하므로 어떤 화면에서도 같은 배치

## 단축키

| 키 | 동작 |
|---|---|
| `F` | 전체화면 전환 |
| `Space` | 시작 / 일시정지 |
| `R` | 초기화 |

## 수정하기

- 공지 문구: `index.html`의 `<section class="notice">` 안 `<li>` 항목
- 헤더 제목: `<header>` 안 `<strong>`
- 기본 시간(40분): 스크립트의 `let totalMs = 40 * 60000;`

## 참고

- 알림음은 브라우저 정책상 페이지를 한 번 클릭한 뒤에만 재생됩니다. 시작 버튼을 마우스로 누르면 종료 알림음이 정상적으로 납니다.
- 글꼴(Noto Sans KR, Roboto Mono)은 Google Fonts에서 불러오며, 인터넷이 없으면 시스템 글꼴로 대체됩니다.
